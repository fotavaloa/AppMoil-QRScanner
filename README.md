Aplicación móvil desarrollada en **Flutter** que permite escanear códigos QR de forma rápida, segura y eficiente. Ideal para proyectos que requieren validación de códigos, registro de asistencia, inventarios u otros procesos basados en lectura QR.

---

## 🚀 Características principales

- 📷 **Escaneo de códigos QR** usando la cámara del dispositivo  
- ⚡ **Lectura en tiempo real**  
- 🔄 **Autofocus y detección automática**  
- 🌓 **Compatibilidad con Android y iOS**  
- 📄 **Visualización del contenido escaneado**  
- 📤 **Opción de copiar o compartir el resultado** (si se implementa)

---

## 🛠️ Tecnologías utilizadas

- **Flutter** (Dart)
- Paquete para escaneo:  
  - `qr_code_scanner` **o**  
  - `mobile_scanner`  
- **Material Design**
